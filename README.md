## 외워타자 — 따라 쓰며 외우는 영어 문장

한컴타자의 "문장 넣기"처럼 외우고 싶은 영어 문장을 넣고, 따라 치다 보면 외워지는 타자 연습 사이트예요.

- `index.html`을 브라우저로 열면 바로 써요. (설치할 것 없음)
- **칸에 쓰기**: 영어 칸과 뜻 칸에 쓰고 `Enter`로 다음 칸으로. 여러 줄을 붙여 넣으면 한 줄씩 나눠져요. 뜻은 안 써도 돼요.
- **한꺼번에 붙여넣기**: 한 줄에 하나, 뜻은 `영어 문장 / 한국어 뜻`(또는 `|`)이나 바로 아래 줄(`→ 뜻`)에 써요.
- 연습은 4단계로 점점 가려져요: **따라 쓰기 → 빈칸 채우기 → 첫 글자 힌트 → 외워 쓰기**
- 틀린 문장은 정답을 보고 바로 고쳐 쓰고, 마지막에 복습으로 다시 나와요.
- 키: `Enter` 또는 마침표 뒤 `Space` 다음으로 · `Tab` 다음 단어 힌트 · `Esc` 정답 보기
- 넣은 문장과 외운 기록은 브라우저(localStorage)에 저장돼요.
- 세트 카드의 **공유**를 누르면 그 세트가 담긴 링크가 만들어져요. 친구가 링크를 열면 같은 문장을 자기 세트로 추가할 수 있어요. (외운 기록은 같이 가지 않아요)
- 사이트 주소: https://s26064-crypto.github.io/TIL2/
- 고칠 때: `app.js`나 `style.css`를 바꾸면 `index.html`의 `?v=` 숫자를 하나 올려요. (안 그러면 브라우저에 남은 예전 파일이 섞여 버튼이 안 먹을 수 있어요)
